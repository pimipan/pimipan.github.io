设施管理团队平稳过渡

在设施服务团队切换期间，运营中断、知识流失与服务标准下降是最直接的风险。项目重点不是“更换人员”，而是把岗位、知识、标准和现场节奏完整迁移。

CHALLENGE / 挑战

在不显著干扰日常运营的前提下完成团队过渡，并让新成员快速适应现场的特殊设施要求。

ACTION / 行动

组织招聘与岗位匹配，建立现场培训、技术知识传递和服务标准对齐机制，跟踪过渡期工作质量。

OUTCOME / 结果

完成新团队组建与培训，保持现场服务连续性，并通过技术培训提升团队整体能力。

2021.10—2021.12LAB / HVACROLE / HVAC ENGINEER

二级生物安全实验室 HVAC 项目

实验室设施的价值不只来自安装完成，更来自可验证的环境控制和可执行的运行程序。项目同时处理系统设计、现场交付与后续维护要求。

CHALLENGE / 挑战

为微生物与分子研究提供稳定环境，并满足国家标准及生物安全协议对 HVAC 运行的要求。

ACTION / 行动

参与 HVAC 系统设计、安装与维护，围绕实验室环境制定专用操作程序和运行控制要求。

OUTCOME / 结果

完成系统交付并建立适用于实验室场景的运行程序，为后续安全、稳定使用提供基础。

锅炉低氮燃烧器更换

设施改造必须同时满足法规、供能连续性与投资合理性。该项目以更严格的氮氧化物排放标准为触发点，在既有酒店供汽约束下完成设备更换。

CHALLENGE / 挑战

在满足新排放标准的同时控制停机影响，确保酒店蒸汽供应不中断。

ACTION / 行动

统筹端到端维护计划、改造节奏与供应保障，并将项目结果与可持续发展目标对齐。

OUTCOME / 结果

完成燃烧器改造与合规目标，保障蒸汽供应，并成功获得政府补贴。

570,000㎡ 超高层综合体暖通运营

在办公、零售、酒店和观光等不同业态共同运行的超高层建筑中，暖通服务必须平衡舒适度、能效、应急响应与政府合规要求。

CHALLENGE / 挑战

面对多业态、超大体量和高服务标准，保障暖通系统稳定运行并快速处理紧急维修。

ACTION / 行动

监督维护质量，推动节能项目，协调政府环境检查，并准备 BOMA 奖项评估材料。

OUTCOME / 结果

保持复杂建筑暖通运行与安全合规，并通过新的维护方法持续改善系统效率。
